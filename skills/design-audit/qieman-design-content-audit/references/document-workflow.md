# Document Workflow

## PDF / Word / 飞书导出稿

- 保留页码和章节
- 区分正文、批注、修订和删除线
- 记录版本日期
- 表格和正文分开提取
- 图片与图表内文字单独检查
- 保留脚注编号和注释关系

## HTML

- 提取可见文本
- DOM 层级
- 按钮、标签、列表
- `alt` 和 `aria-label`
- 隐藏文本
- 重复组件
- 占位数据
- 装饰性英文和模拟数据

## Spreadsheet / 文案表

- 明确字段和页面映射
- 保留编号
- 检查空单元格含义
- 数字、单位、符号和时间口径作为整体核对

## 生产页面

- 记录页面 URL 和核查时间
- 区分固定文案和实时数据
- 对动态数据标记核查时点
