# Audit Rules

## 精确对照原则

默认以 Source 原文为准。

同义改写、语序变化和限定词遗漏不能自动判为一致。

## 文案完整性

先做结构级比对，再做逐字比对：

1. 页面是否齐全
2. 模块是否齐全
3. 段落是否齐全
4. 句子是否齐全
5. 字词是否齐全

## 数字核对

数字、单位和符号必须作为一个整体核对：

```text
数字 + 单位 + 范围符号 + 时间口径
```

示例：

```text
Source：近1年年化收益5.20%
Target：一年收益5.2%
```

该问题不是单纯格式差异，而是周期和收益口径变化。

## 时间核对

时间核对必须同时检查：

- 起点
- 终点
- 截至日期
- 周期
- 时态
- 统计频率

## 合规核对

合规相关信息优先级高于普通文案。

发现疑似违规表达时：

- 原文照录
- 指明位置
- 标记疑似风险
- 建议提交正式合规复核
- 不自行给出法律结论

## P1/P2 边界

- 标点、大小写、全半角和顺序不改变含义：P1
- 改变含义：P0
- 语气和装饰性表达：P2
- Source 自身矛盾：P2 待确认
