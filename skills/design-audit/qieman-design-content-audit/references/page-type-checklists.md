# Page Type Checklists

## 策略介绍页

- 策略名
- 策略定位
- 投资目标
- 核心逻辑
- 资产配置
- 适用人群
- 风险等级
- 历史数据和区间
- 年化收益、年均收益、年度收益口径
- 最大回撤
- 比较基准
- 图表标题、图例、单位
- 截至日期
- 调仓与交易规则
- 费率
- CTA
- 风险提示

## 产品详情页

- 产品全称和简称
- 产品代码
- 管理人
- 风险等级
- 起投金额
- 开放时间
- 费率
- 业绩数据
- 数据截至日期
- 适用人群
- 交易说明
- 风险提示

## 活动页 / H5

- 活动名
- 活动时间
- 参与条件
- 奖励规则
- 券面额
- 使用门槛
- 有效期
- 数量限制
- CTA
- 活动说明
- 风险和免责声明

## 报告页

- 客户名或报告对象
- 统计区间
- 资产总额
- 持仓数据
- 图表单位
- 小数位和千分位
- 结论与建议
- 页码和脚注
- 数据来源
- 风险说明

## 海报 / Banner / 弹窗

- 主标题
- 核心数字
- 活动时间
- 门槛
- CTA
- Logo 和品牌名
- 风险提示
- 装饰性文字
- 与落地页内容一致性
