# qieman-design-content-audit

且慢设计内容核查 Skill。

## 目录

```text
qieman-design-content-audit/
├── SKILL.md
├── README.md
└── assets/
    └── visual-audit-report.html
```

## 默认输出

生成一个可独立打开的 HTML 核查报告：

- 直接显示原设计稿
- 只标注有问题的位置
- 正确区域不标注
- 同一错误多次出现时逐一标记
- 点击问题清单跳转到准确位置
- 不需要再次打开 Figma 查找

## 推荐调用

```text
调用 qieman-design-content-audit，
以需求文档为准，核对设计稿。
输出 HTML 核查报告，只标注有问题的位置。
```

skills/design-audit/qieman-design-content-audit/
