## V0.4.0 — 2026-07-15

### 新增

- 页面类目标可输出独立的可视化 HTML 核查报告。
- 在原页面或页面截图上使用红色标记明确指出错误位置。
- 页面标记与右侧问题清单支持双向跳转。
- 支持 HTML DOM 文本自动标注和截图坐标覆盖标注。
- 支持多页面切换、优先级筛选、搜索和缩放。
- 同一错误字段重复出现时全部标记。
- 分别统计“问题项数量”和“实际出现位置数量”。
- 新增 `references/visual-html-report.md`。
- 新增 `assets/visual-audit-report.html`。


## V0.3.0 — 2026-07-15

### 新增核查维度

- 文案完整性：缺失、多出、整段遗漏
- 文字内容：标题、正文、按钮、标签、角标、占位符、注释脚注
- 数据与数字：金额、百分比、数量、日期、小数点精度、千分位
- 单位与符号：货币、时间、百分号、数学符号、连接符号、序号和特殊符号
- 时间周期表述：时间段、周期描述、截至/截止、时态、频率
- 合规文案：风险提示、免责声明、违禁词、历史业绩、监管信息

### 重构问题优先级

- P0 必须修正
- P1 建议修正：标点、大小写/全半角、排版顺序
- P2 可选优化：语气偏差、需求文档自身问题、装饰性文字

### 其他

- 新增 `references/audit-dimensions.md`
- 更新报告模板和 JSON Schema
- 新增问题升降级规则
