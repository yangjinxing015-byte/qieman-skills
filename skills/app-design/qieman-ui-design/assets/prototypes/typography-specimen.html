使用原则

  • 单卡片字号层级 ≤ 3
  • 风险提示 ≥ 11px 且对比度可读
  • 数字配单位、时间口径、来源
  • 标题建立判断，正文解释原因
  • 不混用多个无关字体家族

避免

  • 同屏堆叠 5+ 字号
  • 把风险藏成过浅灰 / 过小字
  • 用超大装饰字抢过核心数据
  • 正文低于 15px 做长段落
  • 硬编码与 token 不一致的字号
