# qieman-marketing-visual-design

且慢营销视觉设计 Skill。

## 用途

在页面结构、文案、数据已经稳定的基础上，单独增强：

- KV
- Hero
- 头图
- 背景图
- 主题插画
- 无字营销视觉
- 透明前景视觉

## 与主 Skill 的关系

```text
qieman-business-content-design
负责页面

qieman-marketing-visual-design
负责视觉增强
```

推荐先完成页面，再单独优化 KV。

## 默认原则

- 不改页面结构
- 不改文案
- 不改按钮
- 默认无字
- 保留标题安全区
- 避免泛金融 AI 套路
- 一张图一个主视觉中心
- 优先可被 HTML 直接使用的视觉资产

## 当前版本

Draft v0.1.0


## 新增固定规则

### Hero / KV 与正文衔接
当页面顶部存在 Hero / KV，且下方进入正文内容区时，正文内容容器顶部默认采用**20px 圆角衔接（1倍图）**，形成自然过渡，不做生硬直切。
