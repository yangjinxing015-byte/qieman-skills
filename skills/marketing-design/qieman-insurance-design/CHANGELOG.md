# Changelog

## V2 — 2026-09-10

### Architecture
- 将 `qieman-insurance-design` 明确为 `marketing-design` 下的 L2 保险垂类 Skill。
- 直接依赖由 `qieman-ui-design` 调整为 `qieman-business-content-design`。
- `qieman-ui-design` 与 `qieman-brand-guidelines` 改为通过母 Skill 继承。

### Removed duplication
- 删除 / 下沉通用业务内容页布局规则。
- 删除 / 下沉基础 UI Token、基础组件、Responsive、HTML 通用规则。
- 删除 / 下沉通用原型处理、通用 CTA 与 KPI 基础规范。

### Insurance-only rules retained / strengthened
- 保险险种路由与信息优先级。
- 保险 Hero 构图、人物融合与背景过渡。
- 基础 UI Icon / 保险专业 Icon 分层。
- 轻量保险插画、医疗场景插画与人物资产。
- 保险责任、限制、免责、数据与事实保护。
- 保险信息可视化映射。
- 保险专项验收。

### Parent-skill alignment
- 明确同层级 KPI 采用等权展示。
- 明确固定吸底 CTA 继承母 Skill 的单一整行大按钮，不因保险原型出现双按钮或左右分栏而覆盖。
