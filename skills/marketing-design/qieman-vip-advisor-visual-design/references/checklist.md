# Visual QA Checklist

## Brand

- [ ] Logo 使用正确
- [ ] Logo 未变形
- [ ] 品牌色正确
- [ ] 视觉风格与系列一致

## Portrait

- [ ] 人物身份正确
- [ ] 面部未被改动
- [ ] 人物清晰
- [ ] 抠图边缘干净
- [ ] 比例正常
- [ ] 未遮挡核心信息
- [ ] 同系列人物脸部视觉尺寸基本统一

## Content

- [ ] 姓名正确
- [ ] 电话正确
- [ ] 执业编号正确
- [ ] 从业年限正确
- [ ] 服务数据正确
- [ ] 学历正确
- [ ] 资格正确
- [ ] 二维码为正确素材

## Layout

- [ ] 文字未溢出
- [ ] 长姓名适配合理
- [ ] 执业编号未异常换行
- [ ] 人物与文字关系平衡
- [ ] 安全边距正确
- [ ] 层级清晰

## Readability

- [ ] 姓名清晰
- [ ] 电话清晰
- [ ] 编号清晰
- [ ] 关键数字醒目但不过度
- [ ] 小字在最终输出尺寸下仍可读

## QR

- [ ] 二维码未变形
- [ ] 二维码安全区完整
- [ ] 二维码可正常扫码

## Export

- [ ] 已交付 HTML 文件
- [ ] 已交付 3× JPG（RGB）
- [ ] 3× 尺寸正确：横版 `2199 × 1209` / 竖版 `1242 × 2163` / 海报 `2250 × 3000`
- [ ] JPG 由 3× 渲染导出，不是 1× 拉伸
- [ ] 人物和文字均无明显压缩失真
