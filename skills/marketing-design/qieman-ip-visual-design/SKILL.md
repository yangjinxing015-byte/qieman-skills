## 1. Skill 定位

`qieman-ip-visual-design` 用于生成且慢品牌小顾 IP 相关视觉物料。

当前第一阶段主要服务 **内容封面类场景**，包括：

- 今日小 Tips 封面
- 策略介绍封面
- 投前测评封面
- 观点型标题封面
- 社群运营图
- 活动运营图
- IP 内容视觉物料

后续可扩展至 App 内 IP 引导图、节日 IP 物料、视频封面等更多 IP 应用场景。

## 4. 默认输出数量与候选方案约束（强约束）

### 默认输出策略

- 默认每次输出 **4 张候选图**，用于让用户自行选择更合适的方案。
- 若用户没有明确指定输出数量，统一按 **4 张** 执行。
- 仅当用户明确要求“只出 1 张 / 2 张 / 指定张数”时，才按用户要求调整输出数量。

### 资产调用优先级（最高优先级）

本 Skill 的默认执行方式是 **素材拼版 / 图层合成**，不是重新生成背景、Logo、图标或 IP。

必须直接调用 `assets/` 中已有素材作为图层使用：

```text
assets/background/qieman-blue-cover-bg.png
assets/logo/qieman-logo.png
assets/logo/qieman-logo.svg
assets/ip/*.png
```

强约束：

- 背景必须直接使用 `assets/background/` 中的原图。
- Logo / icon 必须直接使用 `assets/logo/` 中的原图。
- 小顾 IP 默认优先使用 `assets/ip/` 中的官方 PNG 原图。
- 当用户明确要求更多动作、金融属性动作或延展形象时，允许基于小顾 IP 延展形象比例生成新动作。
- 不得重新生成背景。
- 不得重新绘制 Logo / icon。
- 不得把小顾 IP 改成真人、动物、其他卡通形象或新的 3D 角色。
- 不得改变 IP 的头身比例、五官气质、品牌蓝色体系和整体材质。
- 既有 IP 素材允许的操作仅限：等比缩放、移动、图层叠放、必要的画布边界裁切。
- 新增 IP 动作必须严格参考小顾延展形象比例，不得低幼化、夸张化、表情包化。
- 不允许非等比拉伸、风格化、滤镜化、重新上色、加描边、加阴影或局部重绘背景与 Logo / icon。

### 多张输出一致性要求

同一轮输出的 4 张图，需保持以下内容一致：

- 同一背景素材
- 同一 Logo / icon 素材
- 同一主题
- 同一文案内容
- 同一主视觉结构
- 同一品牌基调
- 同一基础模板规则
- 同一输出比例与尺寸规范

4 张图的差异应主要体现在：

- 选择不同的 `assets/ip/` 官方 IP PNG 素材，或在用户明确要求时使用不同的 IP 延展动作
- IP 动作 / 表情 / 金融属性道具的轻微差异
- 内容区排版细节的轻微变化
- 留白与图层关系的轻微变化

无论 IP 动作如何变化，IP 在画面中的视觉高度、底部基线和右下展示区域必须保持一致。

不允许 4 张图之间差异过大，避免偏离同一组候选方案的比较目的。

### IP 素材轮换规则（强约束）

- 当一次输出 4 张时，必须从 `assets/ip/` 中选择 **4 个不同的官方 IP PNG 素材**。
- 同一批次内，IP 素材不可重复。
- 默认情况下，4 张图优先切换 IP 官方素材，不重新生成 IP 动作。
- 当用户明确要求更多动作、金融属性动作或延展形象时，允许基于小顾 IP 延展形象比例生成新动作。
- 新动作不得低幼化、夸张化或娱乐化。
- 新动作可以带有轻量金融属性，如数据卡、趋势图、配置卡、基金卡、债券卡等。
- 若使用新动作，4 张图的 IP 视觉高度、底部基线和右下位置必须保持一致。

### 推荐素材选择

生成 4 张时，优先从以下官方素材中选择 4 个不同文件：

```text
assets/ip/xiaogu-question.png
assets/ip/xiaogu-thinking.png
assets/ip/xiaogu-data-card.png
assets/ip/xiaogu-data-laptop.png
assets/ip/xiaogu-idea-bulb.png
assets/ip/xiaogu-cute-hands.png
assets/ip/xiaogu-happy-confetti.png
assets/ip/xiaogu-celebration.png
```

### 素材匹配建议

| 内容类型 | 推荐素材 |
|---|---|
| 疑问 / 问答类 | `xiaogu-question.png` |
| 投前测评 / 思考类 | `xiaogu-thinking.png` |
| 数据分析 / 收益说明 | `xiaogu-data-card.png` 或 `xiaogu-data-laptop.png` |
| 灵感 / 小知识 | `xiaogu-idea-bulb.png` |
| 轻松提示 / 活动 / 正向反馈 | `xiaogu-happy-confetti.png` 或 `xiaogu-celebration.png` |
| 亲和陪伴 / 内容提醒 | `xiaogu-cute-hands.png` |

### 模板适配规则

以“视觉一：Logo + 主标题 + 内容 + IP”为例：

- 4 张图均遵循同一模板结构：
  - 顶部 Logo
  - 主标题区
  - 内容区
  - 右下小顾 IP 素材
- IP 可根据素材本身比例，在右下区域做等比缩放和移动。
- IP 不得遮挡标题与正文关键信息。
- 4 张候选图均应达到可直接选择使用的完成度。

### 输出目标

- 一次给用户提供 4 张风格统一、素材真实、IP 不同、可直接对比的候选图。
- 保证用户可以从中快速选择最合适的一张。
- 保证背景一致、Logo 一致、IP 原图一致、信息可读性和画面完成度。

当用户调用本 Skill 生成内容封面时，默认遵循以下优先级：

```text
1. 优先直接调用 assets 中的背景、Logo / icon 和 IP 官方素材

```

## 10. IP 动作延展与固定展示比例规范

本节用于约束小顾 IP 在内容封面中的动作延展、金融属性表达、展示区域、位置和比例。

### 10.1 默认优先级

IP 使用遵循以下优先级：

```text
1. 优先直接调用 assets/ip/ 中已有官方 PNG 素材
2. 当用户明确要求“更多动作 / 新动作 / 金融属性动作 / 延展形象”时，允许基于小顾 IP 延展形象比例生成新动作
3. 新动作必须严格保持小顾 IP 的头身比例、五官气质、材质、蓝色体系和品牌识别
4. 无论使用已有素材还是生成延展动作，画面中的 IP 展示尺寸、底部基线和右下位置都必须保持稳定
```

### 10.2 允许的动作方向

IP 动作可以更多元化，但必须保持专业、友好、可信，不得低幼化、夸张化或娱乐化。

允许优先使用以下动作方向：

- 挥手欢迎
- 站立微笑
- 思考 / 提问
- 查看平板 / 屏幕
- 手持透明数据卡
- 手持金融图表 / 趋势面板
- 指向图表 / 信息卡
- 讲解配置卡 / 策略卡 / 基金卡
- 轻度点赞 / 点头认可
- 自然陪伴站立

### 10.3 金融属性表达

IP 可以带有轻量金融属性，但金融元素必须作为辅助信息，不得抢占主视觉。

允许出现：

- 透明玻璃质感数据卡
- 折线图 / 趋势图 / 柱状图
- 配置卡 / 基金卡 / 债券卡
- 简洁数据面板
- 小型问号、灯泡、箭头等认知提示元素

禁止出现：

- 复杂大面积金融场景
- 过多图表堆叠
- 强营销感道具
- 与金融无关的大面积装饰
- 玩具化、低幼化、表情包化动作

### 10.4 IP 展示区域与大小比例

IP 是辅助视觉，不是主视觉主体。画面优先级必须始终保持：

```text
1. Logo
2. 主标题
3. 正文内容
4. IP 辅助视觉
```

强约束：

- IP 固定放在画面 **右下角**。
- IP 不要过于靠上，避免影响正文阅读。
- IP 不得遮挡标题和正文。
- IP 不得占用大面积篇幅，不得压过文字内容。
- IP 高度、宽度和展示面积必须严格参考已确认样张。
- 同一组 4 张候选图中，IP 的视觉高度必须保持一致。
- 多张小红书封面并排展示时，IP 底部基线和视觉高度应保持统一。
- 不管 IP 是站立、挥手、思考、手持卡片还是金融属性动作，都必须控制在同一展示区域内。
- 不得因为动作不同导致 IP 忽大忽小、忽高忽低。

### 10.5 固定画面比例参考

以 900 × 1200 输出尺寸为基准，视觉一封面中的 IP 推荐控制为：

```text
IP 展示区域：画面右下角
IP 底部基线：靠近画面底部安全区，保持稳定
IP 顶部高度：不得进入正文主阅读区
IP 视觉高度：参考已确认样张，不可明显放大或缩小
IP 视觉面积：辅助级别，不作为主视觉主体
```

如果不同动作的 IP 原始 PNG 尺寸不同，应通过等比缩放统一其视觉高度，而不是直接按原始像素尺寸放置。

### 10.6 宽高比例与形象约束

- IP 必须等比缩放。
- 禁止横向或纵向压缩。
- 禁止拉伸导致头身比例变化。
- 禁止改变五官比例。
- 禁止低幼化。
- 禁止变成其他机器人、动物、真人或泛卡通形象。
- 禁止改色、重绘材质或改变品牌蓝色质感。
- 禁止为适配画面而裁掉头部、脸部、主体识别区域。
- 如需裁切，只允许轻微裁切脚部或底部阴影，且不得影响主体识别。

### 10.7 与文字排版关系

文字内容优先级高于 IP。

- 主标题不得为了给 IP 让位而压扁、拉伸或变形。
- 正文不得为了给 IP 让位而压缩字形。
- 字体必须保持正常比例，不允许出现明显横向压扁或纵向拉伸。
- 主标题与正文之间的间距应参考确认样张，避免过大导致版面松散。
- 如果 IP 与正文冲突，应优先降低 IP 展示区域或右移 / 下移 IP，而不是压缩文字。
- 如果文案较长，应优先调整字号、行距和内容区宽度，不得挤压文字形态。

### 10.8 四张候选图一致性

默认一次输出 4 张时：

- 4 张必须保持同一背景素材。
- 4 张必须保持同一 Logo / icon 素材。
- 4 张必须保持同一标题和正文文案。
- 4 张必须保持同一版式结构。
- 4 张 IP 可以切换动作或形象，但必须保持相同视觉高度、底部基线和右下展示区域。
- 4 张 IP 不得忽大忽小。
- 4 张 IP 不得忽高忽低。
- 4 张文字不得出现不同程度压缩或变形。

## 12. 风险提示规范

当前默认风险提示：

```text
投资有风险 风险自担
```

### 位置

- 固定左下角
- 小字号
- 低透明度白色
- 弱化处理
- 不抢主视觉

风险提示适用于视觉二、视觉三、视觉四。

### 视觉一内容区换行规则

视觉一中的内容文案应优先保持自然阅读完整性。

#### 单句内容优先单行展示

当内容为单句，且长度不超过 18 个中文字符时，应优先完整展示为一行。

推荐：

```text
【7】买入多少天开始有收益？
```

不推荐：

```text
【7】买入多少天
开始有收益？
```

#### 编号与正文之间不加多余空格

推荐：

```text
【7】买入多少天开始有收益？
```

不推荐：

```text
【7】 买入多少天开始有收益？
```

#### 一行放不下时的处理优先级

如果内容一行展示空间不足，应按以下优先级处理：

```text
1. 适当缩小内容字号
2. 适当增加内容区宽度
3. 调整内容区位置
4. 最后才考虑换行
```

不得为了平均排版或视觉居中，强行拆断完整句子。

#### 换行原则

只有在以下情况才允许换行：

- 内容明显超过一行承载范围
- 文案本身包含多个语义段
- 用户明确要求分行
- 单行会严重挤压 IP 或破坏画面留白

换行时必须按自然语义断句，不得拆散固定词组、问题句或完整表达。

## 14. 标题断句规则

标题文本必须按自然阅读习惯断句，优先依据语义结构、固定搭配和完整概念进行换行，不得为了平均字数而生硬拆分文案。

### 1. 按语义块断句

推荐：

```text
不要让波动打败
你的投资计划
```

不推荐：

```text
不要让波动打败你的
投资计划
```

### 2. 不打断引号内完整表达

推荐：

```text
什么叫
“黎明前的黑暗”？
```

不推荐：

```text
什么叫“黎明前的
黑暗”？
```

### 3. 不拆散固定搭配

不要拆散：

```text
投资计划
市场波动
资产配置
持有收益
短期稳健
活钱管理
```

### 4. 标点跟随句尾

不允许：

```text
什么叫“黎明前的黑暗”
？
```

- 禁止背景、IP、Logo 与参考图风格不一致

## 17. 质量检查清单

生成或交付前必须检查：

- [ ] 背景直接调用 `assets/background/` 原图，未被重新生成或重绘
- [ ] Logo / icon 直接调用 `assets/logo/` 原图，未被重新生成或重绘
- [ ] 文字保持正常字形比例，没有横向压扁、纵向拉伸或明显挤压
- [ ] IP 固定在右下角，未过于靠上
- [ ] 同一组 4 张候选图中，IP 视觉高度和底部基线保持一致
- [ ] IP 展示区域严格参考确认样张，没有过大占用画面
- [ ] IP 动作如有延展，保持小顾头身比例、五官气质和品牌蓝色体系
- [ ] IP 动作如有金融属性，仅使用轻量数据卡 / 趋势图 / 配置卡等辅助元素

- [ ] 默认输出 4 张候选图，除非用户明确指定其他数量
- [ ] 4 张候选图主题一致
- [ ] 4 张候选图文案一致
- [ ] 4 张候选图品牌基调一致
- [ ] 4 张候选图模板结构一致
- [ ] 4 张候选图直接调用 4 个不同的官方 IP PNG 素材
- [ ] 每张图都可作为独立候选成品
- [ ] 输出尺寸为 900 × 1200
- [ ] 比例为 3:4
- [ ] 背景直接使用官方统一背景素材，未重新生成
- [ ] 背景未被改色、重绘或错误裁切
- [ ] Logo / icon 固定左上，并直接使用官方素材
- [ ] Logo 未变形、未改色
- [ ] 小顾 IP 如出现，固定右下且不露脚
- [ ] 小顾 IP 直接调用官方 PNG，未重新生成、未变形、未改脸、未改色、未低幼化
- [ ] 字体使用阿里巴巴普惠体
- [ ] 主标题为第一视觉重点
- [ ] 内容区清晰可读
- [ ] 风险提示位置正确且弱化
- [ ] 标题断句自然
- [ ] 引号内完整表达未被拆开
- [ ] 标点未单独成行
