# Financial Compliance

## 1. Required Principles

- 不承诺收益
- 不暗示保本
- 不制造稳赚、必涨、无风险等预期
- 不用夸张暴富视觉
- 涉及产品、策略、历史业绩时保留风险提示

## 2. Prohibited Copy

避免：

- 稳赚
- 保本
- 必涨
- 闭眼买
- 无风险
- 保证收益
- 错过就亏
- 确定性机会

## 3. Preferred Copy Tone

使用：

- 邀请式
- 克制
- 有门槛
- 有认知筛选感
- 长期主义
- 专业但不夸张

## 4. Risk Disclosure

默认风险提示：

```txt
市场有风险，投资需谨慎
```

九宫格可只在第9格出现一次，单张海报放底部。

## 5. Threshold Copy

资产门槛可以明确表达，但不要把门槛包装成收益保证。

可以：

- 资产300万+准入
- 高净值用户专属
- 席位有限，择人而入

避免：

- 进入圈层即可获得更高收益
- 300万用户稳赚机会
