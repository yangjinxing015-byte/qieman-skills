# Visual Language

## 1. Translation Method

```txt
主题文案
→ 提炼核心判断
→ 转译为高阶语义
→ 选择1个隐喻家族
→ 选择1个主符号
```

不要从“金融”直接跳到K线、交易屏幕、金币或复杂大屏。

## 2. Theme Mapping

| 主题 | 高阶语义 | 主符号 | 可选辅助 |
|---|---|---|---|
| 300万+、门槛 | 准入、筛选、边界 | 半开门、唯一空席 | 邀请函、门缝光 |
| 席位有限 | 被保留的位置、时间窗口 | 空椅、席卡 | 暖金聚光 |
| 信息源 | 视野高度、信息到达 | 灯塔、海平线、透镜 | 指南针投影 |
| 对的圈子 | 同频、共识、连接质量 | 同心圆、轨道、圆桌光 | 少量节点 |
| 私享机会 | 隐秘路径、提前抵达 | 窄光束、封缄信封 | 地图一角 |
| 已经布局 | 先手、判断差异 | 一枚棋子、已亮路径 | 弱网格 |
| 筛掉噪音 | 过滤、纯净连接 | 点阵筛选、少量亮点 | 细连接线 |
| 投研观点 | 观察、研判、结构 | 棱镜、观测台、星图 | 弱数据纹理 |
| 全球视野 | 坐标、航线、全局观 | 星盘、航线、世界压纹 | 极简连线 |
| 长期陪伴 | 时间、耐心、稳定 | 年轮、山脊、远方微光 | 缓慢光轨 |

## 3. Visual Families

### Threshold Arrival

适用：门槛、席位、邀请、不是所有人能进。

画面：

- 深色空间
- 半开的门
- 一束暖金光
- 门外大面积留白

### Scarce Conversation

适用：同频、少数人的交流、深度对话。

画面：

- 圆桌局部
- 少量座席
- 中心一束光
- 不使用多人群像

### Hidden Path

适用：机会不公开、少数人的方向、长期路径。

画面：

- 山路、海面光路或暗流
- 远方微光
- 单一路径

### Selective Connection

适用：筛选、价值网络、认知相近的人。

画面：

- 大量暗点
- 少量亮点
- 简洁连接

### Signal Emergence

适用：认知差、信号、判断力。

画面：

- 黑场
- 单一亮点
- 透镜或局部显影

### Chess & Layout

适用：布局、先手、长期博弈。

画面：

- 局部棋盘
- 一枚棋子
- 方向性光影

### Long-term Track

适用：复利、时间、穿越周期。

画面：

- 年轮、缓慢光轨、山脊或长桥
- 不画暴涨曲线

## 4. Light Finance Elements

最多使用1处：

- 低透明度趋势线
- 极简资产配置圆环
- 抽象坐标网格
- 世界轮廓压纹
- 研究卡片边框
- `market insight`、`long-term`、`risk control`等小标签

不得变成复杂仪表盘。

## 5. Premium Identity Props

可选1个：

- 围棋或国际象棋单子
- 邀请函、封蜡、席卡
- 私享座椅
- 高级钢笔、皮质笔记本
- 徽章、印章、定制卡片

避免：豪车、豪宅、香槟、名表、金条等俗奢表达。

## 6. Composition Formula

```txt
75%–88% 深色基底
+
8%–18% 文字和留白层
+
3%–8% 金色焦点
```

每格：

```txt
1个主符号
+
1处聚光
+
45%–65%留白
```
