# VIP Poster & Page Rules

本文件保留原 Skill 中所有非九宫格的核心页面能力。用于单张完整海报、无字背景、H5头图和多张系列海报。

## 1. 适用范围

- 高净值投资圈邀请海报
- 300万+资产门槛宣传
- 投资圈层席位开放
- 信息源、判断力、认知圈层
- 投研观点、严选机会、全球视野
- 长期价值陪伴
- 顾问朋友圈单图
- 私域社群宣传图
- H5头图、活动页主视觉
- 后期排版用无字背景

不适用于普通大众促销、电商大促、复杂数据报告、App常规交易UI、后台系统或非且慢品牌页面。

## 2. 页面类型

### 2.1 完整单张海报

默认尺寸：1080×1920，9:16。

页面结构：

```txt
顶部品牌区 7%–10%
主标题区 20%–28%
副标题/卖点区 12%–20%
主视觉区 38%–48%
底部品牌收口 8%–12%
```

必须包含：

- 顶部官方“盈米基金｜且慢”Logo
- 2–4行主标题，主标题为第一视觉中心
- 0–3个简短卖点
- 中下部主视觉
- 品牌蓝弧形底部收口
- “安放财富 · 静待花开”
- “市场有风险，投资需谨慎”

正式成稿推荐通过设计软件或HTML/CSS叠加准确文字和Logo，背景由生图工具生成。

### 2.2 无字海报背景

用户明确要求不要文字/Logo时：

- 不生成标题、Logo、Slogan或风险提示
- 顶部与中上部预留55%–65%干净留白
- 中下部放1个主视觉
- 底部预留品牌蓝弧形收口区域
- 不把关键主体放入标题安全区

### 2.3 H5头图 / 页面主视觉

按用户给定尺寸执行。未指定时沿用竖版海报构图逻辑。

必须预留：

- 顶部导航或Logo安全区
- 主标题与副标题安全区
- CTA或卖点区域（用户有需求时）
- 视觉主体区
- 页面向下衔接的渐隐或弧形收口

H5头图不强制放完整风险提示；如果它本身承担独立营销成稿或涉及产品、策略、历史表现，则在可见区域保留风险提示。

### 2.4 多张系列海报

- 尺寸和版式骨架统一
- Logo、字体、底部收口和合规位置统一
- 色彩系统和光源逻辑统一
- 每张使用不同视觉隐喻家族
- 不允许只换角度、颜色或同一会议室背景
- 每张仍限制为1个主视觉、最多2个辅助物

## 3. 三套配色场景

### Palette A：深蓝金

适合：300万+门槛、席位、私享圈层、邀请制。

- 背景：#0A1F3D
- 标题：#E8D5A3
- 强调：#C9A962
- 辅助文字：白色

### Palette B：黑蓝金

适合：高端观点、会员专属、私域邀请、深度对话。

- 背景：#0D1526
- 标题：#C9A962或白色
- 强调：#D4AF37

### Palette C：浅蓝白

适合：信息源、收益天花板、认知判断、投研和长期主义。

- 背景：#E8F2FA
- 标题：#1A3A5C
- 强调：#C9A962
- 底部仍保留品牌蓝收口

金色只作重点，建议占3%–8%，不得大面积铺满。

## 4. 页面组件

### Brand Header

- 深色背景使用白色Logo
- 浅色背景使用品牌蓝Logo
- 顶部左对齐或居中
- 清晰但不抢主标题
- 不拉伸、旋转、压扁或变形

### Title Hero

- Source Han Serif CN Bold/Heavy
- 2–4行
- 重点词可用香槟金或浅金
- 行距紧凑但不拥挤

适合强调：300万+、投资圈、信息源、收益天花板、全球视野、严选机会、席位、门槛。

### Selling Points

- 最多3项
- 每项一句话
- 可用1px金色细线或小圆点分隔
- 不把海报做成权益清单页

### Visual Hero

- 位于中下部
- 1个主场景、1个主视觉
- 最多2个辅助物
- 最多1–2张极简透明数据卡
- 背景低对比、低密度
- 留白55%–65%

### Footer

- 品牌蓝弧形收口：#1B88EE
- Slogan位于弧形区域
- 风险提示弱化但可读
- 不隐藏或删除风险提示（完整独立海报）

### Threshold Badge

- 使用Heavy宋体
- 香槟金
- “300万+”必须远距离可读
- 不与过多说明文字挤在一起

### Data Card

- 半透明、边框克制
- 只做全球视野、配置、研究或风险辅助
- 不形成复杂报告或金融大屏

## 5. 页面模式

### Pattern A：门槛 / 席位

适用：300万+、不是所有人都能进、席位有限。

语义：准入、筛选、被保留的位置。

推荐：半开门、唯一空席、封缄邀请函、私享门廊、圆桌席卡。

默认配色：深蓝金或黑蓝金。

### Pattern B：信息源 / 判断力

适用：投资信息源、收益天花板、进对圈子。

语义：视野高度、信息到达、判断边界。

推荐：海平线、落地窗、灯塔、透镜、指南针投影、研究桌面局部。

默认配色：浅蓝白或理性深蓝。

### Pattern C：投研 / 全球视野

适用：投研观点、严选机会、全球资产配置。

语义：观察、筛选、洞察、全局观。

推荐：观测台、星图、棱镜、航海图纹理、世界轮廓压纹、极简研究卡片。

不要使用满屏金融大屏、复杂图表或密集国家标签。

### Pattern D：长期主义 / 穿越周期

适用：长期陪伴、看得更远、走得更稳。

语义：时间、耐心、稳定、远方。

推荐：山脊、海面航线、树木年轮、慢河、长桥、日出前微光。

自然景观必须服务金融主题，不做旅游宣传图。

### Pattern E：私享机会 / Alpha

适用：机会不在公开渠道、对的圈子、提前布局。

语义：隐秘路径、非公开流动、提前抵达。

推荐：窄光束、暗流、封缄信封、地图一角、隐约路径。

### Pattern F：布局 / 观望

适用：有人已布局，有人仍观望。

语义：先手、策略、判断差异。

推荐：一枚已落棋子、已点亮路线、分割光影。

## 6. Logo符号延展

且慢圆形符号可作为：

- 金属或玻璃装置
- 桌面摆件
- 空间门洞
- 会客厅艺术装置
- 水晶品牌符号

必须保持原始识别关系，不做结构性变形、破碎、拉伸或过度发光。正式Logo优先后期叠加官方资产。

## 7. 完整海报 vs 背景图判断

- 用户说“海报/宣传图/成稿”：默认完整海报
- 用户说“背景图/不要文字/不要Logo”：默认无字背景
- 用户说“H5头图”：根据需求判断是否包含标题；未明确时优先生成可排版背景
- 用户要求多方案：根据其是否要求文字决定完整成稿或背景组

不得把所有单张任务都强制改成无字背景；也不得在用户只要背景时擅自加字。

## 8. 质量检查

### Brand

- 是否符合且慢专业、宁静、长期主义
- Logo是否使用官方资产并保持比例
- 色彩是否为蓝金/黑金/蓝白体系

### Audience

- 是否具有门槛、圈层和认知价值感
- 是否避免普通理财促销或奢侈品炫耀

### Layout

- 完整海报是否1080×1920（除非用户另有尺寸）
- 标题是否第一视觉中心
- 主视觉是否集中在中下部
- 底部收口、Slogan、风险提示是否完整

### Visual

- 一个主要焦点
- 留白充足
- 金色克制
- 不出现绿色主调、金融大屏、金币或多人群像

### Series

- 多张是否统一但每张具有不同视觉切入点
