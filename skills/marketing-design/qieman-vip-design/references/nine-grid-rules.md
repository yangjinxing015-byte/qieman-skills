# Nine-grid Rules

## 1. Mode Decision

### Storyboard Mode

使用条件：

- 只有主题
- 少于9条文案
- 用户要求先看方案、分镜或提示词

### Production Mode

使用条件：

- 已有完整9条文案
- 用户要求直接出九宫格

默认采用：

```txt
视觉背景或CSS符号
+
HTML/CSS排版
```

### Split Mode

只在用户明确要求拆成9张时使用。

## 2. Reading Order

```txt
1 2 3
4 5 6
7 8 9
```

用户顺序不可被默认版式重排。

## 3. Copy Mapping

### Complete Copy

当用户提供9条文案：

- 逐条映射
- 不重写
- 不插入
- 不合并
- 不移动到所谓“更适合”的格子

### Incomplete Copy

当用户提供N条，N<9：

```txt
第1–N格：使用用户原文
第N+1–9格：根据主题补齐
```

如果用户明确要求“不补文案”，剩余格使用纯视觉、品牌或留白卡。

### More Than Nine

默认使用前9条；其余内容不强行压入已有格子。

## 4. Slash Handling

用户使用 `/` 时，默认解释为：

```txt
主标题 / 副标题
```

允许：

- 调整换行
- 规范标点
- 将前半句设为主标题
- 将后半句设为副标题

不允许：

- 改变语义
- 替换为新观点
- 删除门槛、数字或核心判断

## 5. Long-copy Strategy

处理优先级：

```txt
增加文字区域
→ 缩小视觉符号
→ 调整换行
→ 适度缩小字号
→ 用户允许后再压缩文案
```

每格建议：

- 主标题2–3行
- 副标题1–2行
- 总行数不超过5行
- 不使用小段落

## 6. Default Structure

仅在用户未指定逐格内容时采用：

| 格 | 作用 |
|---|---|
| 1 | 提出情绪或问题 |
| 2 | 描述现象 |
| 3 | 暗示入口或方向 |
| 4 | 说明筛选机制 |
| 5 | 核心观点 |
| 6 | 解释认知价值 |
| 7 | 路径、时间或陪伴 |
| 8 | 同频、圈层或邀请 |
| 9 | 品牌或行动收口 |

不要把“第4格门槛、第5格中心、第9格收口”写成覆盖用户内容的硬规则。

## 7. Visual Rhythm

建议九格至少包含3种视觉家族：

- 空间：门、席位、圆桌
- 路径：山路、光路、海平线
- 符号：棋子、透镜、同心圆
- 连接：节点、点阵、轨道

同一视觉家族最多连续使用2格。

## 8. Center Emphasis

第5格可通过以下方式增强，但不更改其文案：

- 字号提升10%–20%
- 对比度更高
- 减少视觉符号
- 增加金色边线或中心聚光

## 9. Brand Placement

- Logo建议只在1、5或9格出现一次或两次
- Slogan和风险提示优先放第9格
- 不要每格重复Logo
- 正式Logo由模板叠加，不由生图模型生成

## 10. Production Validation

### 3秒测试

缩小预览后，3秒内能判断：

- 主题是什么
- 哪一格是视觉重心
- 是否属于高净值观点型传播

### 远距测试

至少3个主符号仍能辨认。

### 降噪测试

- 遮住图像，文案仍成立
- 遮住小字，视觉仍成立
- 文案和图像互相增强，而非互相遮挡
