# Prompt Templates

提示词保持短而明确，不把所有规则一次塞入。

## 1. 单张无字海报 / H5背景

```txt
生成一张{尺寸}、{比例}的且慢高净值私域视觉背景，不要文字，不要Logo。

主题：「{主题}」
高阶语义：「{语义}」
只使用一个视觉隐喻：「{主符号或微叙事情境}」。

整体使用{深蓝金/黑蓝金/浅蓝白}配色，专业、克制、宁静、高端。顶部和中上部预留约60%干净留白，中下部放主视觉，底部预留品牌蓝收口或页面衔接区域。

不要K线、交易屏幕、复杂金融大屏、金币钞票、多人会议、绿色主调、促销感、文字、Logo或乱码。
```

## 2. 完整单张海报制作指令

```txt
先按“单张无字海报背景”生成主视觉；再使用确定性排版完成1080×1920完整海报：顶部放官方“盈米基金｜且慢”Logo，中上部放2–4行主标题，必要时加入不超过3项卖点，中下部放主视觉，底部使用#1B88EE品牌蓝弧形收口，并准确放置“安放财富 · 静待花开”和“市场有风险，投资需谨慎”。不要让生图模型生成中文和Logo。
```

## 3. 多张系列背景

```txt
围绕同一主题生成{数量}张高净值视觉背景。统一尺寸、深蓝金/黑蓝金品牌系统、光源和材质；每张分别使用不同隐喻家族：{方向列表}。每张只保留一个主视觉和最多两个辅助物，预留标题安全区。不要文字、Logo、K线、金币、多人会议或绿色主调。
```

## 4. 九宫格单格背景

```txt
生成一张1:1正方形高端观点卡背景，不要文字和Logo。
观点：「{文案}」
视觉家族：「{家族}」
唯一主符号：「{符号}」
标题区域：「{左下/右侧/中心}」
深蓝黑背景，局部香槟金高光，预留50%–65%文字空间。最多加入一处低透明度金融纹理。
```

## 5. 九宫格背景组

```txt
为同一组高净值九宫格生成9张无字正方形背景。统一深蓝黑与香槟金色调、统一光源和材质。每张只使用一个主符号：{1–9符号列表}。不生成文字、Logo、数字或风险提示。工具多图一致性较差时改为逐格生成。
```

## 6. 生图模型直接带字兜底

仅用户明确要求时：

```txt
生成一张完整1080×1080九宫格总图，3×3排列，严格按从左到右、从上到下放置9条短文案。每格只用一个极简符号，统一深蓝黑与香槟金风格。不要Logo，风险提示只放第9格。主标题尽量不超过12字，副标题不超过18字，确保边缘不裁切。
```

该模式不能稳定保证中文，正式交付应回到HTML/CSS模板。

## 7. Tool Adaptation

### Midjourney

- 优先英文
- 明确 `no text, no logo`
- 竖版使用 `--ar 9:16`
- 强调 `semantic metaphor, not literal finance`

### SDXL

- 正向提示写明唯一隐喻和标题安全区
- 负向提示写明 text、logo、financial dashboard、trading screen、candlestick chart

### 即梦 / 万相 / 文心

- 先写主题语义，再写唯一视觉隐喻
- 明确不要文字、不要Logo、不要直白金融元素

### ChatGPT Image / Firefly

- 优先生成无字背景
- 精确文字和官方Logo后期叠加
