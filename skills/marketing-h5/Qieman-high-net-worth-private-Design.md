# 高净值私域 Design Skill

> Version: V0.1.1  
> Skill Name: `Qieman-high-net-worth-private-Design`  
> 中文名：高净值私域 Skill  
> 适用于且慢高净值用户私域宣传海报、投资圈层邀请图、300万+资产门槛海报、投研观点/严选机会/全球视野主题图、顾问朋友圈转发图、九宫格传播图等。  
> 目标：把高净值私域传播中的视觉风格、版式结构、品牌规则、文案逻辑和九宫格传播方法沉淀成一套可复用的 **高净值私域营销视觉生成规范**。

## 1. Skill Overview

### 1.1 适用范围

本 Skill 适用于：

- 且慢高净值私域宣传海报
- 高净值投资圈邀请图
- 300万+资产门槛海报
- 投资圈层席位开放海报
- 私享投资机会传播图
- 投研观点 / 严选机会 / 全球视野主题图
- 顾问朋友圈转发图
- 私域社群宣传图
- H5 头图 / 活动主视觉图
- 九宫格传播图
- 高净值权益拆解图
- 高净值圈层价值传播图

### 1.2 不适用范围

不适用于：

- 普通大众理财促销海报
- 电商大促类活动图
- 低幼卡通插画图
- 红包雨 / 抢购类营销图
- 复杂数据分析报告
- PC 官网整站
- App 常规交易 UI
- 后台管理系统
- 非且慢品牌视觉页面

### 1.3 核心定位

高净值私域宣传不是普通理财广告，也不是产品促销图，而是一种：

```txt
有门槛
有筛选
有圈层
有认知同频
有长期价值
有专业陪伴感
```

的私域邀请视觉。

本 Skill 的核心表达：

```txt
蓝金 / 黑金高端视觉
+
Source Han Serif CN 标题
+
盈米基金｜且慢 Logo 体系
+
300万+ 门槛前置
+
圈层、信息源、投研能力、长期陪伴的价值表达
```

### 1.4 AI Image Tool Compatibility

本 Skill 需要适配市面主流 AI 生图工具，包括但不限于自然语言生图工具、带参数控制的生图工具、支持负面提示词的生图工具、支持参考图 / 风格图的生图工具，以及设计软件中的 AI 生图能力。

#### 1.4.1 通用适配原则

生成提示词时，必须采用工具无关的结构化描述，不依赖某一个平台专属语法。

通用提示词应包含以下 7 个部分：

```txt
主题文案
画面目标
视觉方向
版式结构
品牌与风格
尺寸比例
禁止项 / 负面提示词
```

要求：

- 核心提示词优先使用自然语言描述，方便复制到任意 AI 生图工具。
- 工具参数单独放在末尾，不写进核心画面描述中。
- 如果工具支持负面提示词，则将“禁止项”独立放入 Negative Prompt。
- 如果工具不支持负面提示词，则将禁止项以“不要……”形式写入主提示词结尾。
- 如果工具支持参考图，应优先上传用户提供的参考图作为风格参考。
- 如果工具支持尺寸参数，单张海报使用 `1080×1920` 或 `9:16`，九宫格单格使用 `360×360` 或 `1:1`。
- 如果工具不支持精确像素，只要求比例：单张海报为 `9:16`，九宫格单图为 `1:1`。

#### 1.4.2 成稿模式与背景模式

由于不同 AI 生图工具对中文文字、Logo 和复杂版式的还原能力不同，本 Skill 默认支持两种生成模式。

##### A. 直接成稿模式

适用于能够较好生成中文文字、Logo 和完整海报版式的工具。

要求：

- 画面中包含标题、Logo、主视觉、底部 slogan 和风险提示。
- 主标题需要靠近最终设计稿效果。
- 适合快速出方向稿和概念稿。

注意：

- 如果工具生成的中文文字、Logo 或风险提示出现错字、变形、乱码，应切换为背景模式。

##### B. 无字背景模式

适用于大多数 AI 生图工具的稳定生产流程。

要求：

- AI 只生成高净值视觉背景和主视觉场景。
- 不生成中文标题、Logo、slogan 和风险提示。
- 画面需要预留标题区、Logo 区和底部收口区。
- 后期在 Figma / Photoshop / Canva / 即梦画布 / 设计工具中叠加准确文字、Logo 和风险提示。

推荐优先级：

```txt
正式设计交付：优先使用无字背景模式
快速概念探索：可使用直接成稿模式
```

#### 1.4.3 跨工具参数转换

当不同工具参数不同，应按以下方式转换。

单张海报：

```txt
目标尺寸：1080×1920
目标比例：9:16
关键词：vertical poster, 9:16, premium financial poster
```

九宫格单图：

```txt
目标尺寸：360×360
目标比例：1:1
关键词：square social media grid image, 1:1
```

如果工具支持风格强度：

```txt
风格强度：中等
参考图权重：中高
文字生成：弱化或关闭，正式文字后期添加
```

如果工具支持负面提示词：

```txt
negative prompt:
绿色主调，低幼卡通，电商促销感，土豪金，豪车，金条，钞票堆，杂乱文字，乱码，错误中文，变形 Logo，过度霓虹，廉价科技感，人物比例异常，拥挤构图，复杂报表，普通理财广告感
```

#### 1.4.4 通用提示词结构

所有 AI 生图工具都应尽量使用以下提示词结构：

```txt
生成一张且慢高净值私域宣传视觉，主题为「{主题文案}」。
画面面向高净值用户，用于私域传播，体现300万+资产门槛、专属投资圈层、专业投研能力、优质信息源、长期价值陪伴。
视觉方向选择「{视觉方向}」，画面包含「{核心元素}」。
整体风格为深蓝金/黑金/浅蓝白高级金融视觉，专业、大气、克制、高端、安静、可信，有且慢品牌气质。
构图为9:16竖版海报，顶部预留品牌Logo区域，中上部预留大标题区域，中下部为主视觉，底部预留蓝色弧形收口与风险提示区域。
主标题字体风格参考 Source Han Serif CN / 思源宋体 CN Bold，重点词可用浅金色强调。
不要绿色主调，不要低幼卡通，不要电商促销感，不要土豪炫富，不要满屏金币钞票，不要复杂报告堆砌，不要杂乱。
```

如使用无字背景模式，应改为：

```txt
生成一张无文字的且慢高净值私域宣传背景图，尺寸比例9:16。
画面需要预留顶部Logo区、中上标题区、底部品牌收口区，不出现任何中文文字、英文字母、Logo、水印和乱码。
只保留高净值场景、金融数据元素、品牌蓝金氛围和主视觉构图，方便后期叠加准确文字与Logo。
```

#### 1.4.5 跨工具验收规则

无论使用哪类 AI 生图工具，输出后必须检查：

- 是否符合目标比例：单张 9:16，九宫格 1:1？
- 是否符合高净值用户审美？
- 是否有圈层感、门槛感、专业感？
- 是否避免绿色主调和促销感？
- 是否存在中文乱码、错误文字、变形 Logo？
- 如果文字或 Logo 不准确，是否已切换为无字背景模式？
- 是否预留了后期叠加标题、Logo、slogan 和风险提示的空间？
- 是否能被 Figma / Photoshop / Canva 等设计工具继续加工？

## 2. Core Brand Principles

### 2.1 高净值门槛感

画面必须让用户第一眼感受到：

- 这不是普通理财服务
- 这是面向高净值用户的专属圈层
- 有明确资产门槛
- 有筛选机制
- 不是所有人都能进入

推荐表达：

- 资产300万以上
- 300万+
- 高净值人士专属
- 不是所有人都能进
- 席位有限，短暂开放

### 2.2 圈层与同频感

高净值私域宣传的重点不是“卖产品”，而是强调：

- 与认知相当的人同行
- 进入更高质量的信息圈层
- 交流环境纯粹
- 资源、观点和机会在对的圈子中流通

推荐表达：

- 只与认知相当的人同行
- 进对圈子，比选对产品重要
- 筛掉的是噪音，留下的是同频
- 有些投资机会，只在对的圈子里流通

### 2.3 专业可信

视觉必须体现金融专业感，而不是奢侈品炫耀感。

要求：

- 场景高级但克制
- 图表简洁专业
- 文案不承诺收益
- 风险提示必须保留
- 不制造焦虑
- 不夸张渲染暴富、稀缺、抢购

### 2.4 长期主义

且慢高净值私域视觉应传达长期陪伴、理性配置和穿越周期的气质。

推荐元素：

- 帆船
- 海面
- 远山
- 山湖书房
- 城市远景
- 指南针
- 书桌研究
- 长期价值曲线

避免：

- 短期暴涨暗示
- 抄底焦虑
- 夸张收益承诺
- “稳赚”“必涨”“闭眼买”等表达

### 2.5 克制高级

整体要高端，但不能土豪化。

可以使用：

- 深蓝
- 黑金
- 香槟金
- 米白
- 浅蓝白
- 金属细节
- 玻璃质感
- 高级商务空间

避免：

- 大面积土豪金
- 豪车炫耀
- 金条钞票堆
- 过度奢侈品化
- 红金促销感
- 廉价霓虹科技风

## 3. Canvas & Size Rules

### 3.1 Single Poster Canvas

单张海报尺寸：

```txt
1080 × 1920
```

比例：

```txt
9:16
```

适用：

- 朋友圈竖版海报
- 私域转发图
- 顾问宣传图
- H5 头图
- 高净值圈层邀请页
- 投研观点完整表达页
- 私享机会主题图

### 3.2 Grid Poster Canvas

九宫格单格尺寸：

```txt
360 × 360
```

整体结构：

```txt
3 × 3
```

适用：

- 朋友圈九宫格
- 社群传播
- 高净值权益拆解
- 投资圈层主题系列图
- 活动预热
- 顾问私域连续传播

### 3.3 Size Priority Rule

当用户未明确说明尺寸时：

- 如果用户说“单张海报”“宣传图”“竖版海报”，默认输出 `1080×1920`
- 如果用户说“九宫格”“朋友圈九图”，默认输出 `360×360 × 9`
- 如果用户要求多张同主题海报，保持 `1080×1920` 系列一致性
- 不再使用旧版 `1125×2436` 作为默认尺寸

## 4. Brand Identity Rules

### 4.1 Default Brand Logo

单张海报顶部默认使用：

```txt
盈米基金｜且慢
```

要求：

- 深色背景使用白色 Logo
- 浅色背景使用蓝色 / 彩色 Logo
- Logo 位置清晰但不抢主标题
- Logo 与顶部边距保持高级留白
- 不得拉伸、压扁、旋转或变形

### 4.2 Logo Placement

单张海报推荐：

- 顶部左对齐
- 或顶部居中
- 与主标题保持稳定距离

九宫格推荐：

- 第1格、第5格、第9格可放品牌 Logo
- 其他格子可不放完整 Logo，避免重复拥挤
- 深色格使用白色 Logo
- 浅色格使用蓝色 Logo

### 4.3 Qieman Symbol Extension

且慢圆形 Logo 可延展为：

- 品牌奖杯
- 金属装置
- 玻璃装置
- 数据中台中心符号
- 桌面摆件
- 空间门洞
- 会客厅艺术装置
- 透明水晶品牌符号

要求：

- 保持原始识别关系
- 不做结构性变形
- 不过度发光
- 不做低清、破碎、拉伸处理

### 4.4 Bottom Brand Closure

单张海报底部统一使用：

```txt
安放财富 · 静待花开
```

并在 slogan 下方加入风险提示：

```txt
市场有风险，投资需谨慎
```

风险提示要求：

- 字号小
- 弱化处理
- 可读即可
- 不抢主视觉
- 不隐藏、不删除

## 5. Typography Rules

### 5.1 Main Title Font

主标题统一使用：

```txt
Source Han Serif CN / 思源宋体 CN
```

推荐字重：

```txt
Bold / Heavy
```

### 5.2 Secondary Text Font

副标题、正文和卖点文字：

```txt
Source Han Serif CN Regular / Medium
```

数据小字、图表标签、小号说明文字可使用：

```txt
Source Han Sans CN Regular / Medium
```

主标题应体现：

- 稳重
- 典雅
- 正式
- 金融品牌感

避免：

- 普通黑体大标题
- 卡通字体
- 圆体
- 促销字体
- 过度装饰字体

- 大字号
- 行距紧凑但不拥挤
- 留白充足
- 重点词可使用浅金 / 香槟金强调

适合强调的关键词：

- 300万+
- 300万以上
- 投资机会
- 投资圈
- 对的圈子
- 收益天花板

## 6. Color System

### 6.1 Core Palette

本 Skill 以蓝金体系为基础。

核心色彩：

```txt
深蓝 / 黑蓝 / 品牌蓝 / 浅蓝 / 香槟金 / 浅金 / 米白 / 白色
```

色彩含义：

- 深蓝 / 黑蓝：专业、理性、信任、金融感
- 浅蓝 / 蓝白：通透、专业、国际化、长期主义
- 浅金 / 香槟金：尊享、门槛、稀缺、价值感
- 白色 / 米白：干净、克制、留白感

### 6.2 Recommended Ratio

推荐比例：

```txt
蓝色：70%–85%
白色 / 浅色：10%–20%
金色：5%–10%
```

金色只作为重点强调和高级点缀，不可大面积铺满。

### 6.3 Palette A: 深蓝金高净值版

适合：

- 300万+门槛
- 席位开放
- 私享投资圈
- 高端商务会谈
- 品牌器物
- 专属圈层

视觉特征：

```txt
深蓝背景
浅金标题
白色辅助文字
金色细线 / 光效点缀
高端商务场景
蓝色弧形底部收口
```

### 6.4 Palette B: 黑金高净值版

适合：

- 九宫格
- 高端权益
- 私域邀请
- 会员专属
- 高端会议室

视觉特征：

```txt
近黑深蓝背景
香槟金重点字
金色线条
商务精英 / 城市夜景 / 会客厅元素
高端、稳重、克制
```

### 6.5 Palette C: 浅蓝白专业版

适合：

- 投资信息源
- 收益天花板
- 认知判断
- 山湖书房
- 投研观点
- 长期主义

视觉特征：

```txt
浅蓝白背景
深蓝标题
少量金色重点词
自然远景
书桌 / 电脑 / 山湖 / 帆船
底部保留蓝色弧形收口
```

### 6.6 Color Avoidance

避免：

- 绿色主调
- 土豪金
- 大面积高饱和黄色
- 红色促销感
- 彩虹色科技感
- 廉价渐变
- 过多杂色
- 高饱和赛博霓虹

## 7. Single Poster Layout Rules

### 7.1 Default Structure

单张海报默认结构：

```txt
顶部品牌区
↓
主标题区
↓
副标题 / 简短说明
↓
分隔线 / 装饰点
↓
卖点区
↓
主视觉区
↓
底部蓝色弧形收口
↓
安放财富 · 静待花开
↓
市场有风险，投资需谨慎
```

### 7.2 Layout Ratio

推荐比例：

```txt
顶部品牌区：7%–10%
主标题区：20%–28%
副标题 / 卖点区：12%–20%
主视觉区：38%–48%
底部弧形收口：8%–12%
```

### 7.3 Poster Layout Requirements

单张海报必须满足：

- 尺寸为 `1080×1920`
- 保持 `9:16` 构图
- 顶部 Logo 清晰
- 主标题为第一视觉中心
- 主视觉集中在中下部
- 底部有蓝色弧形收口
- 底部有 slogan 和风险提示
- 画面留白充足
- 信息不堆叠
- 风格贴近用户参考图

正式生产中，优先采用以下流程：

```txt
AI 生成无字高净值背景图
→ 设计软件叠加准确标题
→ 叠加标准 Logo
→ 叠加底部 slogan 与风险提示
→ 人工检查文字、合规、品牌规范
```

仅在工具文字能力足够稳定时，才使用直接成稿模式。
